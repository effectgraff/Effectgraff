# SEO keyword plan for EffectGraff

## Positioning

EffectGraff is a six-artist graffiti and mural collective representing Saint Petersburg, Nizhnevartovsk, Krasnoyarsk, and Vladivostok. The core commercial action is an inquiry about a wall, mural, festival, collaboration, or open call.

Search volume is not included because no verified Wordstat/Search Console dataset was provided. Priorities below are based on business intent, relevance to the current site, geographic fit, and likely ability to rank with focused pages and genuine portfolio evidence.

## Recommended title patterns

1. `EffectGraff — граффити-художники и роспись стен`
2. `Роспись стен и муралы на заказ — EffectGraff`
3. `Граффити-художники для фестивалей и open calls — EffectGraff`
4. `Муралы для брендов, кафе и городских пространств — EffectGraff`

## Content rules

Use one primary intent per page. Do not paste the full keyword list into metadata or visible copy. Each future case study should name the real work, location, year, surface/project context, and the action a prospective client can take. The current home page should remain a strong collective overview; service and city pages should carry the more specific query targets.

## Technical SEO corrections applied in this pass

The canonical URL, Open Graph URL, JSON-LD URL, robots sitemap URL, and sitemap `<loc>` were aligned to `https://effectport-5rhal3bg.manus.space/`, the currently published domain. The obsolete `meta keywords` tag was removed because Google states it has no ranking effect. The title and description now include the strongest relevant commercial phrases while remaining human-readable.
