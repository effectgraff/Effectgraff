# Доступность EffectGraff в России

## Проверено

Текущий адрес `https://effectport-5rhal3bg.manus.space/` из доступной сети отвечает по HTTPS с HTTP 200. DNS разрешается через IPv6-адреса Cloudflare. `robots.txt` разрешает обход и содержит sitemap сайта. Это подтверждает общую публичную доступность, но не доказывает доступность у каждого российского интернет-провайдера.

## Ограничения текущего запроса

Без реальных тестовых подключений российских операторов нельзя гарантировать отсутствие VPN для всей территории РФ. На доступ могут влиять конкретный провайдер, регион, DNS и сетевые ограничения. Manus Help Center указывает, что подключение собственного домена поддерживается для платных пользователей; бесплатным пользователям доступен запрос code package для самостоятельного размещения.

## Потенциальный российский вариант

Официальная документация Yandex Cloud описывает размещение статического HTML/CSS/JavaScript-сайта в Object Storage, поддержку HTTPS и собственного домена. Такой mirror или перенос на российскую инфраструктуру может повысить предсказуемость доступа из РФ, но потребует отдельного аккаунта, домена, настройки DNS/SSL и самостоятельной публикации code package.
